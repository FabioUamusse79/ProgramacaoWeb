Conceitos de CSS

Box Model

Cada elemento possui conteúdo, padding, border e margin.

Display

Define como os elementos são apresentados e organizados na página.

Flexbox

Organiza elementos em linhas ou colunas de forma flexível.

CSS Grid

Organiza o conteúdo em linhas e colunas, formando uma grelha.

Position

Controla o posicionamento dos elementos dentro da página.

Overflow

Controla o conteúdo que ultrapassa os limites de um elemento.
