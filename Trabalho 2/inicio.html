Bem-vindo ao Sistema de Cadastro

Este sistema foi desenvolvido para permitir o cadastro e a consulta de informações dos usuários de forma simples, organizada e responsiva.

Objetivos do sistema

  • Facilitar o cadastro de usuários;
  • Organizar informações pessoais;
  • Permitir a consulta dos usuários cadastrados;
  • Apresentar uma interface simples e fácil de utilizar;
  • Demonstrar a utilização de HTML, CSS e CSS Grid.
