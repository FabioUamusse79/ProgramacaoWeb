Sobre o Projeto

O Sistema de Cadastro de Usuários é uma aplicação Web desenvolvida como parte do Trabalho de Consolidação da disciplina de desenvolvimento Web.

Objetivo

O principal objetivo deste projeto é aplicar os conhecimentos adquiridos sobre HTML e CSS na construção de uma página Web responsiva.

Tecnologias utilizadas

  • HTML5 - estrutura da página;
  • CSS3 - estilização dos elementos;
  • CSS Grid - organização do layout;
  • Responsive Design - adaptação para diferentes tamanhos de ecrã.

Responsividade

O sistema foi desenvolvido para funcionar em computadores, tablets e dispositivos móveis. No computador, a navegação aparece ao lado do conteúdo. Em dispositivos móveis, os elementos são reorganizados verticalmente.

Estrutura do sistema

O projeto é composto por diferentes páginas conectadas através de um menu de navegação, permitindo ao usuário acessar o início, cadastro, lista de usuários, informações sobre o projeto e contacto.
